Data protection

Backups

Every night at midnight the team server copies everything (still encrypted) to a separate backup database in your Cloudflare account. For your own copy, Back up now saves a file locked with a password you choose: it holds customers' ID, so keep the file and the password apart. Purchase records have their own backup in the Buy log.
